# Начните здесь

Для публикации откройте **PUBLISHING.md**. Загружать нужно содержимое этой папки, включая `.github`.

Публичное демо работает на GitHub Pages и хранит изменения только в браузере посетителя. Полная локальная версия описана в README. Ни одна личная база или резервная копия не входит в этот комплект.

Период примеров: октябрь 2026. Реальные названия фирм используются для иллюстрации; счета, условия, сделки, выплаты и записи вымышлены.
