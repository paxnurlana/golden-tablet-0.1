# Проверка границы публичного демо

Цель публикации — показать работу продукта. Этот документ не объявляет серверную версию готовой к эксплуатации с чужими финансовыми данными.

| Область | Публичная версия |
|---|---|
| Выполнение | Только HTML, CSS и JavaScript; серверные API не публикуются |
| Данные | Явно экспортированные вымышленные примеры; 40 сделок и связанные записи |
| Хранение изменений | Локальное хранилище браузера посетителя; общей базы нет |
| Расчёты | Journal — источник результата; Dashboard пересчитывается из текущих записей |
| SQLite и миграции | В публичной сборке не выполняются; файлы базы исключены |
| Доступ и ключи | Для демо не нужны; реальные `.env`, ключи и вложения не включаются |
| Внешние сервисы | AI и брокерские операции не выполняются публичным демо |
| Возврат состояния | Кнопка сброса возвращает исходные примеры |
| Резервные копии | Локальная полная версия имеет отдельный сценарий копирования и проверки восстановления; сами копии не публикуются |
| Публикация пакетов | npm-публикация отключена; workflow релиза пакетов удалён |
| Лицензии | Исходные обязательные уведомления сохранены |

Перед публичным размещением полной серверной версии нужны отдельные проверки авторизации, изоляции пользователей, ограничений загрузки, секретов, миграций, защиты API и восстановления из копии. Проверка статического портфолио не заменяет такую проверку.
