# Локальный журнал: быстрый режим

Для обычного заполнения запустите `Запустить журнал.cmd` в корне проекта.
Адрес: http://127.0.0.1:3001. Окно запуска должно оставаться открытым.
При первом запуске создаётся сборка; следующие запуски её используют.

Команды для разработчика:

- `pnpm local:build` — пересобрать после изменений кода.
- `pnpm local:start` — запустить готовую сборку.
- `pnpm --filter web dev --turbopack -p 3001` — режим редактирования с горячим обновлением.

Быстрый режим не означает, что разработка журнала завершена. Это способ запуска без
компиляции страниц на лету. После правок кода нужна пересборка и перезапуск.

Оба режима используют `apps/web/data`: база и вложения не перемещаются и не очищаются.
Сборка хранится отдельно в `.next-fast`, чтобы не повреждать работающий dev-сервер.
Не запускайте два сервера на одном порту. Сервер быстрого режима доступен только
на этом компьютере (127.0.0.1). GitHub и Supabase для запуска не нужны.
